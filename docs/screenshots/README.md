# README ekran görüntüleri

GitHub ana sayfasında kullanılan görseller bu klasörde tutulur:

| Dosya | İçerik | Hesap |
| --- | --- | --- |
| `dashboard.png` | Metrikler ve grafiklerle personel dashboard'u | Ayşe Yılmaz |
| `internship-tracking.png` | Staj listesi veya staj detay ekranı | Ayşe Yılmaz |
| `intern-submission.png` | GitHub bağlantılı görev teslim formu | Can Öztürk |
| `mentor-review.png` | Bekleyen teslim ve onay/revizyon alanı | Ayşe Yılmaz |

## Görsel standardı

- PNG biçimi ve 16:9 oran kullanın; önerilen boyut `1440 × 900` pikseldir.
- Tarayıcı yakınlaştırmasını `%100` yapın.
- Gerçek kullanıcı, şirket, e-posta, telefon, token veya gizli URL göstermeyin.
- Yalnızca `seed.py` ile üretilen sahte demo verisini kullanın.
- Ekran görüntüsüne tarayıcı yer imleri, işletim sistemi bildirimleri veya başka
  uygulamalar girmemelidir.
