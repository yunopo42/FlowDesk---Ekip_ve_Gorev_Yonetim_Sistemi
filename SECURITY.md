# Güvenlik politikası

## Desteklenen sürüm

FlowDesk henüz kararlı bir sürüm numarası yayımlamadığı için yalnızca `main`
branch'indeki en güncel kod güvenlik düzeltmeleri alır.

## Güvenlik açığı bildirme

Bir güvenlik açığı bulursanız kullanıcı verisini, çalışan exploit kodunu veya
gizli bilgileri herkese açık GitHub issue'sunda paylaşmayın. GitHub deposundaki
**Security > Report a vulnerability** özel bildirim kanalını kullanın. Bu özellik
etkin değilse depo sahibinin GitHub profili üzerinden özel iletişim kurun.

Bildirimde şu bilgileri paylaşın:

- Etkilenen route veya bileşen
- Açığın tekrar üretim adımları
- Olası etkisi
- Varsa önerilen düzeltme

Gerçek şirket veya kullanıcı verisi kullanmayın. Bildirim incelenene kadar açığı
kamuyla paylaşmamanız rica edilir.
